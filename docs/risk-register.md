# Risk Register

| ID   | Risk                                                  | Control                                                                                   | Residual state                                                          | Owner                |
| ---- | ----------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | -------------------- |
| R-01 | Provider configuration changes outside Quantum Parks  | Version mappings, read-back checksums, drift findings, blocked release/readiness          | External provider-console access remains possible for restricted admins | Platform owner       |
| R-02 | Post-call webhook loss or auto-disable                | Fast durable acknowledgement, inbox retry, dead-letter/reconciliation metrics and runbook | Live webhook health cannot be proven without credentials                | SRE                  |
| R-03 | Model fabricates completed action                     | Empty-only model completion field, strict schemas, deterministic outcome policy           | Prompt/model quality still needs corpus validation                      | AI governance        |
| R-04 | Payment data enters transcript                        | Live interruption policy, multilingual deterministic redaction, restricted classification | Native-language edge cases need review                                  | Privacy officer      |
| R-05 | Raw or customer data overexposed                      | RBAC, purpose checks, redacted default view, encrypted storage, audit, retention gates    | Production IAM and KMS evidence external                                | Security owner       |
| R-06 | Simulator mistaken for production                     | Synthetic flags, production readiness rejection, `EXTERNALLY_BLOCKED` state               | Human release process must honor gate                                   | Release manager      |
| R-07 | Unsupported provider feature emulated                 | Five-state capability register and adapter error translation                              | Account entitlements remain unknown                                     | Vendor admin         |
| R-08 | Customer write integration changes a booking/capacity | No booking writes; availability returns `noHold`; secure digital handoff only             | Real booking contract unavailable                                       | Product owner        |
| R-09 | Stale knowledge gives incorrect facts                 | Effective/expiry fields, approval and assignment lifecycle, release gates                 | Approved factual content external                                       | Knowledge owner      |
| R-10 | Dependency or image compromise                        | Lockfile, allowlisted install scripts, CI validation, pinned images/tags                  | SBOM/signing scanner not executed locally                               | Security engineering |
| R-11 | Provider API key leaks through UI, logs, or backups   | Server-only validation, AES-256-GCM vault, separate master key, safe references, audit    | Production secret-manager and key-recovery evidence remain external     | Security engineering |
