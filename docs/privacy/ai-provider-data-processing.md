# AI Provider Data Processing

AIOS sends only context permitted by the active capability and context-policy versions. The Context Builder authorizes source type, purpose, classification, freshness, verification, retention, region, masking, and token budget before provider execution.

Providers do not become authoritative memory. Persistent memory consists only of approved Quantum Parks records and immutable AIOS artifacts. Candidate memory requires validation and promotion. Production remains blocked until provider data region, retention, legal basis, source contracts, and required language reviews are approved.
